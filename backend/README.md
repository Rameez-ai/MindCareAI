# MindCareAI Backend API

This is the FastAPI backend API for the MindCareAI mental health companion, deployed on Hugging Face Spaces.

## Development and Deployment

This Space is configured to run using the `Dockerfile` in this directory. 
When pushed to Hugging Face, it builds and runs automatically on port 8000.
